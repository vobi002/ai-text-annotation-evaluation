# AI Response Evaluation & Annotation Guidelines

## 1. Purpose

These guidelines define a consistent process for evaluating and annotating AI-generated responses.

The goal is to assess whether an AI response is accurate, relevant, clear, helpful, safe, and compliant with the user's instructions.

## 2. Evaluation Criteria

### Accuracy
Check whether the information provided is factually correct and supported by reliable knowledge.

### Relevance
Check whether the response directly addresses the user's question or task without unnecessary information.

### Instruction Following
Check whether the response follows all explicit requirements given by the user, including format, number of items, length, tone, and other constraints.

### Clarity
Check whether the response is understandable, well-organized, and easy to follow.

### Helpfulness
Check whether the response provides useful information that adequately addresses the user's needs.

### Safety
Check whether the response avoids harmful, dangerous, inappropriate, or misleading content.

## 3. Annotation Process

For each AI response:

1. Read the user's prompt carefully.
2. Identify the main task.
3. Identify all explicit requirements.
4. Review the AI response.
5. Check the response against each evaluation criterion.
6. Identify errors, omissions, or instruction violations.
7. Assign appropriate ratings.
8. Provide a concise rationale explaining the evaluation.

## 4. Rating Scale

| Score | Meaning |
|------|---------|
| 1 | Very Poor |
| 2 | Poor |
| 3 | Acceptable |
| 4 | Good |
| 5 | Excellent |

## 5. Important Annotation Rules

- Evaluate the response based on the user's request, not personal preference.
- Do not mark a response as good solely because it is grammatically correct.
- A factually correct response can still be poor if it fails to follow instructions.
- Check every requirement in the prompt.
- Do not assume information that is not present.
- Distinguish factual errors from missing information.
- Provide objective and concise rationales.
- Apply the same standards consistently across different responses.

## 6. Preference Ranking

When comparing two AI responses:

1. Read both responses carefully.
2. Compare them using the same evaluation criteria.
3. Identify which response better satisfies the user's request.
4. Select the preferred response.
5. Explain the decision using specific evidence.

## 7. Quality and Consistency

Annotations should be:

- Accurate
- Consistent
- Objective
- Clearly justified
- Based on the defined criteria

When a case is ambiguous, the evaluator should identify the ambiguity rather than making an unsupported assumption.
