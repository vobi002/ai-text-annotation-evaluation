# LLM Response Evaluation

## Project Overview

This project demonstrates the evaluation of AI-generated responses using a structured evaluation framework.

The goal is to determine whether an AI response is accurate, relevant, clear, helpful, safe, and compliant with the user's instructions.

## Evaluation Task

### User Prompt

> Explain inflation to a secondary school student in Nigeria using a simple example.

### AI Response

> Inflation is when the general prices of goods and services increase over time. For example, if a bag of rice costs ₦40,000 today and later costs ₦50,000, the same amount of money will buy less rice than before.

## Evaluation

| Criterion | Score | Evaluation |
|---|---:|---|
| Accuracy | 5/5 | The response gives a correct basic explanation of inflation. |
| Relevance | 5/5 | It directly explains inflation and provides an example. |
| Instruction Following | 5/5 | It explains the concept simply and uses a Nigerian example. |
| Clarity | 5/5 | The explanation is concise and easy for a secondary school student to understand. |
| Helpfulness | 5/5 | The example makes the concept easier to understand. |
| Safety | 5/5 | The response contains no harmful or inappropriate content. |

## Overall Assessment

**Overall Rating: 5/5 — Excellent**

The response successfully follows the user's instructions and provides an accurate, relevant, and easy-to-understand explanation of inflation.

## Evaluator Rationale

The response is strong because it accurately defines inflation, uses a realistic Nigerian example, and presents the concept in simple language appropriate for a secondary school student. It also follows the user's instruction to keep the explanation simple.

## Areas for Improvement

Although the response is strong, it could be improved by explaining that inflation refers to a general increase in prices across an economy, rather than the price of only one product.

## Evaluation Conclusion

The response meets the main requirements of the task and would be considered a high-quality AI response.
