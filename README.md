# AI Text Annotation & Response Evaluation Portfolio Project

## Project Overview

This project demonstrates practical skills in data annotation and AI response evaluation.

The dataset contains 15 synthetic customer-support-style examples annotated for sentiment, intent, named entities, and AI response quality.

## Project Type

Synthetic Dataset

## Annotation Areas

- Sentiment Classification
- Intent Classification
- Named Entity Recognition (NER)
- AI Response Evaluation

## Tools

- Google Sheets
- Google Docs
- GitHub

## Skills Demonstrated

- Sentiment classification
- Intent classification
- Named Entity Recognition
- AI response evaluation
- Quality control
- Annotation consistency
- Writing concise evaluation rationales
- Identifying sarcasm and ambiguous language
- Detecting unsupported assumptions
- Evaluating instruction following

## Quality Control

Each annotation was reviewed against the defined project guidelines.

Special attention was given to ambiguous language, sarcasm, entity boundaries, relevance, instruction following, unsupported assumptions, and factual consistency.

Where information was not explicitly supported by the text or guidelines, it was not inferred.

## Dataset

The project contains 15 annotated examples covering common customer-support scenarios such as delivery issues, refunds, billing, account updates, technical support, and lost or stolen items.
